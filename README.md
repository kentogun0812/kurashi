# Kurashi

Nền tảng cộng đồng dành cho người Việt Nam sinh sống tại Nhật Bản.

## 🚀 Cách khởi chạy ứng dụng (Getting Started)

1. **Cài đặt dependencies:**
   ```bash
   npm install
   ```

2. **Cấu hình biến môi trường:**
   Tạo file `.env.local` dựa trên `.env.example` và cấu hình các biến môi trường cần thiết (ví dụ: thông tin kết nối Supabase).

3. **Chạy server development:**
   ```bash
   npm run dev
   ```

   Mở [http://localhost:3000](http://localhost:3000) trên trình duyệt để xem ứng dụng.

## 🛠 Công nghệ sử dụng (Tech Stack)

- **Framework:** Next.js 16 (App Router) & React 19
- **Ngôn ngữ:** TypeScript
- **Styling & UI:** Tailwind CSS 4, shadcn/ui (Base-Nova / @base-ui/react)
- **Database, Auth & Storage:** Supabase
- **Đa ngôn ngữ (i18n):** next-intl v4 (hỗ trợ Tiếng Việt, Tiếng Anh, Tiếng Nhật)
- **Icons:** lucide-react
